# 本地调试启动指南

本地用浏览器聊天页调试 Agent，**不连企业微信**，与服务器生产进程互不影响。

| 项 | 本地 | 服务器 |
|--|--|--|
| 端口 | `8101` | `8100` |
| 数据库 | `./data/local_dev` | `./data` |
| 企微 | 关闭 | 开启 |

## 首次准备

```bash
cd /home/terra/programs/hall_agent

# 虚拟环境（有 conda 也可用 conda）
PYENV_VERSION=3.11.9 python -m venv .venv
source .venv/bin/activate

pip install -U pip
pip install -r requirements.txt

cp .env.example .env
# 编辑 .env，至少填写：DASHSCOPE_API_KEY=...
# 本地不必填 WECOM_BOT_ID / WECOM_BOT_SECRET

python -m src.admin.init_db
```

## 日常启动
```bash
cd /home/terra/programs/hall_agent
source .venv/bin/activate
./scripts/start_local.sh
```

浏览器打开：http://127.0.0.1:8101/

可切换单聊 / 群聊，自定义 user_id / chat_id
到期提醒写入本地库，页面右侧显示「本应推送」，不会发到企微
Ctrl+C 停止
健康检查：http://127.0.0.1:8101/health

注意
不要在服务器上跑 start_local.sh 去连生产企微。
本地数据在 data/local_dev/，与生产库隔离。
